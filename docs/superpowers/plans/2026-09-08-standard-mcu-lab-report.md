# 第 2～15 章单片机实验报告统一改版实施计划

> **供智能代理执行：** 必须使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans，按任务逐项实施。本计划使用复选框跟踪进度。

**目标：** 把第 2～15 章的单片机实验统一改造成可打印、可粘贴、可填写的标准实验报告，并在最后删除 Book/lab.tex。

**架构：** 在 Book/colorful.cls 中提供统一的横线填写命令和 8cm × 8cm 粘贴框命令。14 个章节各自保留独立实验内容，但统一使用九段式结构；公共组件只负责排版，章节文件负责实验语义。

**技术栈：** XeLaTeX、colorful 文档类、tcolorbox、tabularx、graphicx。

**规格：** docs/superpowers/specs/2026-09-08-standard-mcu-lab-report-design.md

## 全局约束

- 仅改造第 2～15 章；第 1 章和第 16 章保持不变。
- 统一结构为：实验基本信息、实验目的、实验原理、硬件连接、关键代码、实验步骤、实验现象与数据记录、结果分析、实验总结。
- 不设置实验人员、实验环境与器材、验收结果。
- 所有人工填写内容使用横线，不出现“待填写”或“待记录”。
- 图片和关键代码使用 8cm × 8cm 正方形粘贴框。
- 实验步骤使用 enumerate，每个 item 独占一行，不使用箭头串联步骤。
- 所有新增注释和说明使用中文。
- 不修改正文中的教学代码、公式、原理图和非实验内容。
- 保留用户已有的未提交修改，不覆盖、不还原。
- 最终 XeLaTeX GREEN 编译由用户执行。
- Book/lab.tex 最后删除；Book/lab.pdf 保留。
